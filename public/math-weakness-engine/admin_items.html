2) 검수·수정

3) 등록 목록

batch+items JSON을 붙여넣거나 파일 선택. 먼저 [dry-run]으로 예측 확인 후 [실투입]. 유형 없는 문항은 pending 저장 → 아래 3단 후처리.

5) 유형 일괄 지정 (검수 확정 파일) — 3단: 검수 산출 JSON 업로드

검수가 만든 [{ "id":"…", "problem_type_id":"…" }, …] 파일 업로드 → 버튼 1회로 pending→approved 일괄 승격. (소수 건은 위 목록에서 행별 [유형지정].) ★UNIQUE 충돌 건은 목록으로 표시(미승격 유지).

배치 롤백 (잘못 투입한 배치 되돌리기)

bulk_batch_id로 대상 확인 → 보관(archived, 복구가능) 또는 완전삭제. 먼저 [미리보기]로 건수 확인.
