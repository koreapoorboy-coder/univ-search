# PATCH 1.1 교과 개념 배선 결함 정정 — 검수 및 비교 보고서

## 1. 최종 판단

패치 1은 유지했고, 명세의 결함 3건을 모두 정정했습니다. 검수 과정에서 명세에 없던 **정규화 경계 소실 결함**도 확인되어 함께 수정했습니다.

기존 방식은 공백과 필드 경계를 모두 제거한 뒤 부분문자열을 찾기 때문에 다음과 같은 허위 개념을 만들 수 있었습니다.

- `통계 수행평가` → `계수`
- `완성함` + 다음 필드의 `수소` → `함수`
- `...설명하기` + 다음 필드의 `생명과학...` → `기생`

이 결함을 남긴 채 명세의 `clean 53.40% 이상` 숫자만 맞추면 허위 판정을 복원하게 됩니다. 따라서 본 패치는 **원문 단어 경계와 입력 필드 경계를 보존하는 매칭기**를 적용했고, 감사에는 기존 부록 A 방식과 경계 보존 방식을 함께 남겼습니다.

## 2. 구현 결정 4건

1. **record_only 유지**: 동작은 유지했습니다. `conceptDetail.evidenceScope`에 `guide` / `record` / `both` / `none`을 기록합니다.
2. **Ⅰ·Ⅱ 수준 모집단 유지**: 동일 `task_id` 2,144건을 유지했습니다. 현재 스크립트의 명시적 Ⅱ 판정은 353건입니다(물리 94, 화학 106, 생명과학 85, 지구과학 68). 명세의 357건은 현재 원장과 동일 규칙으로 재현되지 않았으며, `AP 물리학Ⅰ-2`처럼 숫자 2가 있지만 Ⅱ 과목이 아닌 값은 제외했습니다.
3. **CONCEPT_FALLBACK 유지 + 추적성 추가**: `CONCEPT_FALLBACK_ENABLED = true`로 분리했고, `fallbackDerived`, `fallbackHitCount`, `fallbackSourceSubjects`를 기록합니다. 패치 후 fallback-only 판정은 93건입니다.
4. **감사 스크립트 동봉**: `build/audit_concept_wiring.js`가 기존 감사파일의 2,144개 `task_id`를 원장과 전건 조인하여 재현합니다.

## 3. 핵심 지표

### 3-1. 동일 재현 스크립트 · 경계 보존 판정기

| 지표 | 패치 1 재실행 | 패치 1.1 | 변화 |
|---|---:|---:|---:|
| 모집단 | 2144 | 2144 | 0 |
| 개념 판정 | 1300 (60.63%) | 1202 (56.06%) | -98건 |
| clean | 1106 (51.59%) | 1107 (51.63%) | +1건 / +0.04%p |
| name_only | 62 | 0 | -62 |
| record_only | 132 | 95 | -37 |
| 제목 포함관계 중복 | 129 | 0 | -129 |
| 콤마 개념명 제목 표기 | 16 | 0 | -16 |

**판정**

- `name_only = 0` → 통과
- 제목 포함관계 중복 `0` → 통과
- 콤마 개념명 제목 표기 `0` → 통과
- 경계 보존 기준 clean `51.59% → 51.63%` → **+0.04%p, 하락 없음**
- 화학 clean `36.53% → 36.84%` → **+0.31%p**
- 전체 판정률 `60.63% → 56.06%` 하락은 과목명 허위, record-only 잡음, 단어/필드 경계 허위를 제거한 결과입니다.

### 3-2. 명세 부록 A 방식과의 차이

명세 부록 A는 모든 공백을 제거해 검사하므로 실제 원문에 없는 2글자 조합도 `clean`으로 셀 수 있습니다. 패치 1 재실행에서 부록 A 방식은 `53.36%`, 경계 보존 방식은 `51.59%`였습니다. 패치 1.1은 런타임 자체가 경계를 보존하므로 두 방식 모두 실질적으로 동일한 방향으로 수렴합니다.

따라서 외부 검수 기준의 `53.40%`를 숫자 그대로 유지하는 것보다, **동일한 허위 조합을 제거한 경계 보존 기준에서 clean이 내려가지 않는지**를 성공 기준으로 삼는 것이 더 타당합니다.

## 4. 결함별 결과

### 결함 ① 과목명 구간 차단

- 미적분1 일반 안내문 → `subject_fallback`, `matchedTerms=[]`
- 정보 일반 안내문 → `subject_fallback`, `matchedTerms=[]`
- 경계 보존 감사 `name_only=0`

### 결함 ② primaryParent 중복 및 콤마 표기

- `행렬 / 경우의 수 / 경우의 수, 순열, 조합` → `행렬 / 경우의 수`
- `지구 시스템 / 지구시스템` → `지구 시스템`
- 제목 포함관계 중복 `0`, 콤마 제목 표기 `0`
- `conceptDetail.conceptName`은 원본 유지, `conceptDisplayName`만 제목 표기로 분리

### 결함 ③ 1글자 핵심 개념

1글자는 `concept_name`·`core_concept` 출처만 허용하고, 원문 경계 + 문맥 패턴을 함께 적용했습니다. 단순 경계만 적용하면 물리의 `일`이 날짜·일정 문장에서 허위 판정될 수 있어 명세보다 보수적으로 강화했습니다.

- 화학 `몰수비·한계 반응물` → `물질의 양과 화학 반응식` 유지
- `몰 농도` → `몰` 포함 판정 가능
- `몰라도 되는 내용을 몰라서 조사함` → 판정 없음
- 화학 clean 1건 순증

## 5. 추가로 정정한 결함

**단어/필드 경계 소실**을 수정했습니다.

- 입력 각 필드는 `␞` 경계로 분리하여 서로 다른 필드 사이의 문자열 결합을 차단했습니다.
- 사전 용어가 원래 한 단어이면 원문에서도 연속 문자열일 때만 인정합니다.
- 사전 용어 자체에 공백·가운뎃점 등이 있는 경우에만 해당 구분자를 선택적으로 허용합니다.

이 수정으로 학생 안내문에 없는 `계수`, `함수`, `기생` 등의 허위 판정이 제거되었습니다.
