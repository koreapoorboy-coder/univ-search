# A라인 재개 안건 — raw_taxonomy 유형 부재 (재료 상신, 결정 요청 아님)

> (B)에서 고를 수 없는 사안. A라인 재개는 sha256 재검증(45/45 영향)을 동반하므로 A라인 결정 대상.
> 이 문서는 **판단 재료만** 담는다. A라인을 여는 결정이 한 번이면 대기 중인 것을 한꺼번에 처리해야 하므로 함께 올린다.

## 1. 🔴 4단원 — raw_taxonomy 유형 부재 (856문항)
문항의 `primary_problem_type_id`가 raw_taxonomy topic_type에 없음 = **팩 입력에 그 유형이 없음.** 이름·PT-다리 둘 다 낮음. **이름 어긋남 아님.**

| 단원 | 팩 | 키없음/총 | 이름% | PT% | 성격 |
|---|---|---|---|---|---|
| similarity_pythagoras | SM_GS | 300/300 | 34 | 0 | PT-다리 구조 부재(legacy id 미연결) + 이름 저매칭 |
| polynomial_mult_fact | PN_PM | 233/300 | 26 | 22 | raw_taxonomy 유형 부재 |
| quadratic_function | QD_QF | 232/300 | 5 | 23 | raw_taxonomy 유형 부재 |
| geometry_properties | TQ_GP | 91/150 | 7 | 39 | raw_taxonomy 유형 부재(부분) |
| **합** | | **856** | | | |

### 필요 작업 (규모)
1. 이 856문항의 유형을 raw_taxonomy에 **추가**(topic_type + legacy_problem_type_id 연결).
2. 추가 유형에 팩 규칙 **신설**(현 팩이 그 유형명에 발화 안 하므로).
3. 팩 변경 → **45/45 재검증**(sha256 게이트·앵커 불변 확인).
→ Code탭(B) 권한 밖. **A라인 상신.**

## 2. 함께 올릴 것 — D3 드리프트 7규칙 (이미 대기 중)

## 3. 미결 — §10 · v11 미확보
- **§10**(축별 공급원 표·팩주도율): 미확보.
- **v11**(경계 판례): 미확보. **A2/D2 경계**가 여기 걸림(재매핑 보류 3태그 146: mean_formula·squared_deviation·representative_value).

## 4. 참고 — 공통규칙 오탐 (B라인서 마킹, 별건)
연결 파일 10단원에 공통규칙(C-) 포함. 그중 **오탐 대장 4건(C-01→E1·C-06→C2·C-09→B3·C-10→E3) 발화를 각 item `falsepos_rules`에 표시**(되돌리지 않음, 출처 남김).
- 대량: QE C-01:68·C-10:31 · LE C-01:41 · probability C-10:31.
- C-01(「주어진 경우」)·C-10(「개수/연산/값의 범위」)이 E1·E3 과잉공급.
- 이건 공통규칙 정밀화(45단원 스윕+AELF 재계산) 사안이라 **역시 A라인.** 오탐 대장에 이미 유형②로 등재.
