# A라인 재개 안건 — raw_taxonomy 유형 부재 (재료 상신, 결정 요청 아님)

> (B)에서 고를 수 없는 사안. A라인 재개는 sha256 재검증(45/45 영향)을 동반하므로 A라인 결정 대상.
> 이 문서는 **판단 재료만** 담는다. A라인을 여는 결정이 한 번이면 대기 중인 것을 한꺼번에 처리해야 하므로 함께 올린다.

### 필요 작업 (규모)
1. 이 856문항의 유형을 raw_taxonomy에 **추가**(topic_type + legacy_problem_type_id 연결).
2. 추가 유형에 팩 규칙 **신설**(현 팩이 그 유형명에 발화 안 하므로).
3. 팩 변경 → **45/45 재검증**(sha256 게이트·앵커 불변 확인).
→ Code탭(B) 권한 밖. **A라인 상신.**

## 4. 공통규칙 오탐 — 축-단위 심각 (실측 상신)
연결 파일 10단원에 공통규칙(C-) 포함. 오탐 대장 4건(C-01→E1·C-06→C2·C-09→B3·C-10→E3) 발화를 각 item `falsepos_rules`에 표시(되돌리지 않음).
**실측 (C-01 발화 188·C-10 발화 131):**
| | 문항 0축(심각) | 그 축이 오탐 단독(축-단위 심각) |
|---|---|---|
| C-01 → E1 | 0 | **92문항** |
| C-10 → E3 | 0 | **121문항** |
- **문항 단위 경미**(오탐 빼도 0축 0개) → 걷어내기 불요, 표시 유지.
- **축 단위 심각**: E1 92·E3 121 = **213 부착이 오탐 단독 공급.** C-01/C-10이 오탐이면 이 축들은 spurious.
- **⚠ ①과 맞물림**: E1 축 정당성은 원문 확정이나, **이 92문항의 E1 부착은 오탐 경로.** 축≠부착. C-01 정밀화 시 이 92만 재판정.
- 정밀화 = 45단원 스윕+AELF 재계산 → **A라인.**

### ⚠ 오탐 대장 자체가 v10판 (검수 지적)
- 지금 세는 오탐 4건은 **v10 §11 부속 대장(10건)** 기준.
- **v11에는 13건 + 형태③**(한글 활용어미)이 있다고 기록됨. v11 오면 **3건 더**가 지금 구운 10단원에서 발화하고 있을 수 있음.
- → **v11 확보 시 오탐 13건+형태③으로 재스윕 필요.** §10·v11 미확보가 A2/D2뿐 아니라 **여기도** 걸림.
