# 배선 라이브 검증 (QF 전 구간) — 사용자 안내 (2026-08-09)

> 목적: 지금까지 만든 것을 **실제 진단 페이지에서 끝까지 한 번** 돌려 사이 끊긴 데 없는지 확인. 경로:
> 학생코드 → .txt 시험지 업로드 → Worker 진단 → fine태그 → observed_axes → 자동 저장 → profile 조회.
> 확대(19단원) 전에 반드시 통과할 것.

## 0단계 — 사이트 갱신 (선행, 중요)
- 라이브 테스트는 **배포된 진단 페이지**를 쓴다. 학생코드 입력란·자동저장·profile.html·**.txt 업로드**는 **이번 커밋들**에 있으니, **진단 페이지를 호스팅하는 사이트를 최신 커밋으로 갱신**해야 한다(GitHub Pages면 push 후 Actions 초록불 대기 ~1~2분).
- Worker는 이미 배포됨(`/health` version `2026.08.09-fine-error-tags`). 오버레이 200 확인됨.
- ✅ 성공: 진단 페이지 상단 메뉴에 **"학생 프로파일 조회"** 링크가 보이면 새 버전이 떠 있는 것. 안 보이면 갱신 미반영 → 대기/재배포.

## 1단계 — 진단 실행 (단계별)
1. **진단 페이지**(index.html)를 연다. (평소 진단하던 그 주소.)
2. **학생 이름**: 아무거나 (예: `테스트`).
3. **학생 코드**: 숫자 3자리만. 예 `7` 입력 → 칸 옆에 `→ SC-STUDY-007` 뜨는지 확인.
4. **시험 범위**: **수능·모의고사(전체 범위)** 선택(가장 확실 — 이차함수가 후보에 반드시 포함). 학기 모드면 이차함수 있는 학기.
5. **시험지 업로드**: 파일 선택 → 보낸 **`이차함수_검증시험지.txt`** 선택. (파일창에 .txt가 보임 — 이번에 열어둠.)
6. **[1차 진단 시작]** 클릭 → "1차 진단 분석 중" 카드. **1~2분** 소요(Opus). 창 닫지 말 것.

## 2단계 — 각 단계 성공 판정 기준
| 지점 | ✅ 성공 신호 | 위치 |
|---|---|---|
| 코드 입력 | `→ SC-STUDY-007` 미리보기 | 코드칸 옆 |
| 진단 진행 | "분석 중" 카드, 에러 카드 없음 | 결과 영역 |
| 진단 완료 | 취약 개념·행동지시 등 결과 렌더 | 결과 영역 |
| **자동 저장됨** | **"📊 이 학생(SC-STUDY-007) 이전 기록·축 누적 보기 →" 링크 출현** | 결과 위 |
| **누적 조회** | 링크 클릭 → profile.html에 **축 합산(C2/C3/C4 등) + 시험 1건 + 원본 fine태그** 표시 | 새 탭 |
| **fine태그 실측** | profile 시험목록 "관측 태그"에 `quadratic_translation_parameter_sign_confusion` 류 등장 | profile 표 |

- ★ **전 구간 성공의 핵심 신호**: profile.html에 **축 합산이 뜨고, "관측 태그"에 fine태그(긴 서술형)가 보이면** — 코드→업로드→Worker(②)→fine태그→observed_axes(①b)→자동저장(3-A)→조회가 **전부 연결**된 것.
- (2회차) 같은 코드 `007`로 한 번 더 진단하면 profile 축 합산의 "등장 시험수"가 2로 늘고 wrong이 누적 → "반복 취약축" 성립 확인.

## 3단계 — 실패 시 어디를 보나
- **에러 카드가 뜸(진단 자체 실패)**: 카드 문구 확인. Worker 문제면 → `F12`(개발자도구) → **Console** 빨간 오류, **Network** 탭에서 `analyze` 요청 클릭 → Status/Response.
- **진단은 됐는데 "기록 보기" 링크가 안 뜸**(자동저장 실패): `F12` → Console에 `[axis-store] record save skipped` 경고 있는지. 있으면 그 메시지 첨부. observed_axes가 비었을 수도(→ fine태그 미생성, 아래).
- **profile은 뜨는데 "관측 태그"가 짧은 거친태그거나 비어 있음**(fine태그 미생성 = ② 미작동): 오버레이 404(사이트 갱신 안 됨) 또는 Worker 미반영. 0단계·②배포 재확인. profile "축맵ver" 칸이 `fine-tag-to-axis-v1`인지도 확인.
- **profile이 비어 있음**(조회 안 됨): 코드 불일치(입력코드 ≠ 진단코드) 또는 다른 브라우저(localStorage는 브라우저별). 같은 브라우저·같은 코드인지 확인.
- **.txt가 파일창에 안 보임**: 사이트 갱신 미반영(0단계). 최신 배포 후 재시도.
