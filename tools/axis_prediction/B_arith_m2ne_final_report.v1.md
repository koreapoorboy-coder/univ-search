### 이것이 뜻하는 것

**판정불가율은 저작 내용과 무관하게 카탈로그+overlay만으로 결정되는 구조적 지표다.** 처방을 어떻게 쓰든, 배치를 어떻게 짜든 최종값은 바뀌지 않는다(중간값만 편성에 흔들린다 — §5).

⇒ **저작 전에 계산 가능하다.** 따라서:

### M1 재태깅 근거에 미치는 영향

정정된 근거(§5)는 "커버리지가 낮으면 검증이 불가능해진다"였다. 여기에 한 겹이 더해진다 — **그 불가능성은 저작을 시도하기 전에 이미 계산된다.**
M1에 처방 192종을 쓰는 일은 "해 보고 안 되면 재태깅"이 아니라, **안 될 것이 확정된 상태에서 쓰는 것**이다. 재태깅 선행은 시행착오를 줄이는 선택이 아니라 유일하게 성립하는 순서다.

### M1 재태깅 근거 — 정정본 (이것만 인용할 것)

| | 폐기된 근거 | **정정된 근거** |
|---|---|---|
| 주장 | "커버리지가 낮으면 신설이 늘어난다" | "커버리지가 낮으면 **검증이 불가능**해진다" |
| 지표 | 신설률 | **판정불가율** |
| 실측 | 100%→0 · 34%→0 · 19%→**8** (단조 아님, **반증**) | 100%→0% · 34%→**34.6%** · 0%→**100%** (단조) |

**왜 신설률이 근거가 될 수 없나**: tier-2가 자기 overlay 부재를 대신 받는다. 수연산은 M2_GEOM보다 커버리지가 **높은데** 신설은 **더 적다**(0 vs 8). 배치6은 overlay 10%에서도 신설 0이었다.

**두 지표가 재는 것이 다르다**
- 신설률 = 태그를 **붙일 수 있는가**(저작 가능성) → 단원 관측 어휘 풀의 크기·범용성이 결정
- 판정불가율 = 붙인 태그가 **맞는지 확인할 수 있는가**(검증 가능성) → **커버리지가 직접 결정**, 그리고 **저작 전에 계산 가능**(§0)

⇒ **커버리지가 낮아도 처방은 쓸 수 있으나, 그 처방이 맞는지 확인할 수 없다.** 이것이 M1 재태깅의 진짜 근거다.

### 도구가 실제로 잡은 것 (5건)

1. **핵심 도구의 기존 위반** — ASCII 검사를 설치하자 `edit_json_meta.ps1`(`_meta` 파손 재발 방지용 도구) 자체에 비ASCII 3바이트가 있어 실행이 차단됐다. **규칙을 강제하는 도구가 규칙을 어기고 있었고, 그동안 발견되지 않았다.**
2. **설치 직후의 자기 위반** — 가드를 넣은 직후 새 스크립트에 비ASCII를 또 넣었고, **주의력이 아니라 도구가 차단**했다(세션 내 3번째 발생, 첫 자동 적발).
3. **조용한 실패** — 스캐폴더가 한 줄짜리 `.ps1`을 생성했다(PS에서 `,`가 `+`보다 결합력이 강해 배열이 뭉개짐). 1행이 `#`로 시작해 **스크립트 전체가 주석**이 됐고, 실행되고 exit 0인데 출력만 없었다. 그런데 생성기는 **비ASCII 0을 확인하고 `[verified]`를 출력**했다 — 형식만 검사했기 때문이다.
4. **교차 단원 라벨 불일치** — 최종 배치의 `multiple_answer_omission`("복수 답 누락" vs 닮음 "복수 정답 누락"). 검사가 없었으면 두 단원이 다른 이름으로 남았다.
5. **도구의 구조 오판별** — `collect_gaps.ps1`에 M2_GEOM을 물렸더니 `concept_map`을 평면 구조로 오인해 **오류 없이 정상 종료**하며 "판정가능 개념 0"을 출력했다(메타 키를 개념으로 셈). 그대로 갔으면 비교표에 잘못된 분모가 실렸다.

### 여기서 나온 검증 원칙 2개 (§7 등재)

- **검증 기준은 검증 대상과 독립일 것** — *무엇을 기준으로* 재는가.
- **★생성기는 산출물의 "바이트"가 아니라 "동작"을 검증해야 한다** — *무엇을* 재는가(형식 vs 동작). 위 3번이 근거이며 앞 항목과 **다른 실패**다. 둘이 짝을 이뤄야 도구 3종 시험이 완결된다.
- 현행 생성물 검증 4항목: ①비ASCII 0 ②줄 수 ③가드 블록 존재 ④**실제 실행 출력**. ★**④가 실효이고 ①~③은 형식 검사**다 — ①~③만으로는 3번을 잡지 못한다.

### 도구 3종 시험 = 상시 항목

도구를 만들거나 고치면 ①**정상 통과**(기존 입력 결과 불변=회귀) ②**실패**(잘못된 입력에 명시적 실패) ③**오판별**(구조가 다른 입력에 무의미한 출력을 내지 않는가)를 **모두** 시험한다. ★"도구가 무의미한 출력을 낼 때 그것을 알아채는가"는 ①②와 **별개 능력**이다.

### ★알려진 사각지대 (숨기지 않고 기록)

ASCII 자기검사는 **파일 경로 없이 실행하면(내용을 파이프로 밀어 넣는 방식) 우회된다** — `$MyInvocation.MyCommand.Path`가 null이라 검사가 건너뛰어진다. 시험으로 확인했다.
⇒ **도구는 반드시 `powershell -File <경로>`로 실행할 것.** 가드는 만능이 아니다.
