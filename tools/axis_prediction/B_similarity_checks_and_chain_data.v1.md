### 1-2. ★CHECK 9 — 첫 실행에서 오탐 2건. 검사 쪽이 틀렸습니다
```
첫 실행 결과

```

```
       배열 멤버명 'Length'·'Count' 와 매칭됐습니다.  41+1 = 42
       미적분 error_tags 의 정상값 "length"(3건) 도 같은 이유
조치   -ccontains 로 교체. 교정 근거를 코드 주석으로 남김
재실행  진짜 오염은 M2_SIMILARITY_PYTHAGORAS representation_types 528 하나뿐
```
★ 인계문 §7 의 **"검증 기준은 검증 대상과 독립일 것 — 스크립트 오류를 데이터 문제로 오인 말 것"**
과 **"PS 변수명은 대소문자 미구분"**이 같은 자리에서 다시 나왔습니다.
그대로 보고했으면 **멀쩡한 단원 2곳을 오염으로 보고**할 뻔했습니다.

## 3. §3 — 연쇄 밀림 4계열 25행 (자료만)

★ **새 가설을 세우지 않았습니다.** 아래는 전부 측정치입니다.
파일: `B_simpy_chain_shift_series_25.v1.csv` (좌표·라벨·배정·기대 나란히)

### 3-1. 계열별 전량
```
45->47  n=8   학습지 "닮은 두 입체도형의 겉넓이의 비의 활용"
              배정   "닮은 평면도형 넓이비의 활용"

              배정   "닮은 입체도형 겉넓이비의 활용"
              simpy-03 q093,094,095 · simpy-04 q096,097,098 · simpy-05 q093,094,095

49->50  n=6   학습지 "닮음의 활용(1) 높이의 측정"

              배정   "닮은 평면도형 넓이비의 활용"
```

### 3-2. 측정: 네 계열 모두 완전 균일
```
계열     행수  학습지 라벨 종류  배정 base 종류  배치 수  문항번호 범위
45->47     8         1               1            4       91~98
47->48     9         1               1            3       93~98
49->50     6         1               1            3       98~102
45->50     2         1               1            2      102~103
```
★ **한 라벨이 언제나 같은 하나의 잘못된 base 로 갑니다.** 문항별 흔들림이 0입니다.
여러 배치에 걸쳐 동일합니다. 이것은 문항 단위 오류가 아니라 **라벨 단위로 균일한 현상**입니다.

### 3-3. 측정: 칸 수가 일정하지 않습니다
```
45->47  2칸    47->48  1칸    49->50  1칸    45->50  5칸
```
★ "연쇄 밀림"이라는 이름은 **한 칸씩 순차로 밀렸다**를 함의하는데, 실제 간격은 2·1·1·5 입니다.
이름이 현상을 정확히 기술하지 않을 수 있다는 점만 지적합니다. **원인은 말하지 않습니다.**

### 3-4. 이 자료로 검수가 볼 수 있는 것
```
전부 넓이비/부피비/활용 구간(문항번호 91~103)에 몰려 있습니다
배정 base 4종  닮은 평면도형 넓이비의 활용 · 닮은 입체도형 겉넓이비의 활용 ·
               닮은 입체도형 부피비의 활용
기대 base 4종  닮은 입체도형 겉넓이비의 활용 · 닮은 입체도형의 부피비 ·
               닮음의 실생활 활용 - 높이·축척
★ 배정 base 와 기대 base 가 서로의 목록에 겹쳐 나타납니다(겉넓이비의 활용이 양쪽에)
```
이것도 관측입니다. 해석은 검수 몫으로 남깁니다.

## 4. §6 — pos 문서 2곳 정정 (diff 첨부)

### 4-1. 정정 전 실측 근거 확인
```
통계   m3_statistics 카탈로그 PT = 002,005,008,...  전부 3n-1
       표준 pos 분포 = pos1 23종 / pos0 0 / pos2 0     ⇒ "전부 pos 1" 이 옳다
슬롯13 PT037 부재 · PT038 존재 · PT039 부재.  (38-1)%3 = 1  ⇒ "현재 pos1만" 이 옳다
       결손은 72칸 CSV 에 PT037 pos0 "개념·조건 판별" · PT039 pos2 "복합 계산·증명"
       로 이미 표준 표기로 등재돼 있다
```
★ 다른 문서의 주장이 아니라 **카탈로그 실측**으로 확인한 뒤 고쳤습니다.

### 4-2. diff
```diff
 - 통계는 23종 **전부 pos 2**(`계산·해석`)라 74가 상한이 아니라 조립이 닿은 최대 지점이다.
 + 통계는 23종 **전부 pos 1**(`계산·해석`)라 74가 상한이 아니라 조립이 닿은 최대 지점이다.

 + - ★**pos 표준 = (PT − 1) mod 3.** pos0=첫칸 3n-2 / pos1=둘째칸 3n-1 / pos2=셋째칸 3n.
 +   이 문서는 원래 `PT mod 3` 로 적혀 있었다(판정 21차 §6 에서 정정).
```
