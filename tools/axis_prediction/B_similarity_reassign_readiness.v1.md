## 1. §5 — BASE 104건 목표 칸 실재 여부

### 1-1. 목표 칸을 어떻게 정했는가
```
expected_slot   학습지 라벨에서 나옵니다 (판정 23차 §0 에서 라벨 채택 확정)
칸(pos)         D1 배정이 이미 갖고 있는 pos 를 씁니다
                = "밀림은 칸을 보존한다" 관측(판정 20차 §2)의 적용
target_pt       3 x expected_slot - 2 + pos
```
★ **이것은 관측이지 정의가 아닙니다.** 도구가 사용한 pos 를 CSV 에 그대로 찍어 두었으니
검수가 다른 칸을 지정하면 그대로 따릅니다.

### 1-2. 결과
```

### 1-4. ★결손 72칸 목록이 낡았습니다
```

         슬롯 1·3 (미점유·base 이름 없음)        6칸

      ★신규 8칸도 base 이름이 확정돼 있어 기계 도출이 됩니다
      ★슬롯 1·3 의 6칸은 base 이름이 없으므로 계속 제외합니다
