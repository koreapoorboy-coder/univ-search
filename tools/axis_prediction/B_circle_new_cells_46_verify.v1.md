## 1. 생성 규칙의 자기검증 — 먼저 기존 47종에 규칙을 되먹였다

지시받은 규칙이 실제로 기존 47종을 재현하는지 **생성 전에** 확인했습니다.
어긋나면 즉시 throw 하고 아무것도 만들지 않도록 했습니다.

```
47종 전건에 대해 검사한 것
  ① 접미사        (PT-1) mod 3 로 계산한 pos 의 접미사와 ★축자 일치하는가
  ② difficulty    같은 pos 의 difficulty 와 일치하는가
  ③ concept_id    M3_CIRC_C{slot:3자리} 와 일치하는가
  ④ base 충돌     한 슬롯의 여러 칸이 서로 다른 base 를 갖지 않는가
결과  ★47/47 통과. 예외 0.  규칙이 기존 카탈로그의 산출 규칙임이 확인됨
```
★**이 단계를 넣은 이유**: 규칙의 출처가 그 47종이므로, 규칙이 47종을 재현하지 못하면
규칙 해석이 틀린 것이다. 46칸을 만들기 전에 그것을 걸러야 한다.

## 2. 산출 — `B_circle_new_cells_46.v1.csv`

컬럼 (지시받은 9개)
```
slot · pos · pt_no · problem_type_id · base_name · suffix · type_name
· default_difficulty · concept_id
```

적용한 규칙
```
PT = (slot-1)*3 + pos + 1            problem_type_id = M3_CIRC_PT{PT:000}
pos0  기본 판별  basic
pos1  조건 적용  concept
pos2  종합 활용  advanced
base_name  = 그 슬롯의 기존 base_name  ★원문 그대로 (§4 에서 바이트 검증)
type_name  = base_name + " - " + suffix
concept_id = M3_CIRC_C{slot:000}
```

## 4. 추가 검산 3항 — ★주의사항 대응

지시의 ★주의 3건에 각각 대응하는 검사를 붙였습니다.

### 4-1. base_name 원문 보존 — ★바이트 단위 비교

```
base_name 이 원본과 바이트 동일하지 않은 행 : ★0 / 46
방법  UTF-8 바이트 배열로 변환해 길이와 전 바이트를 대조.
      ★문자열 -eq 가 아니라 바이트 비교다. 정규화가 개입할 여지를 없앴다
```

### 4-2. ˚ 기호 (U+02DA) 보존

```
U+02DA 포함 신규 행 : 1
  M3_CIRC_PT043  slot 15 pos 0
  원에 외접하는 사각형의 성질(2); 한 내각이 90˚인 경우 - 기본 판별

U+00B0(DEGREE SIGN) 로 바뀐 행 : ★0
```
★해당 슬롯은 pos0 한 칸만 비어 있었고, 그 한 칸이 정확히 ˚ 를 물고 나왔습니다.

### 4-3. concept / core 혼입 방지

```
default_difficulty 에 'core' 가 들어간 행 : 0
  (생성 규칙이 pos -> {basic, concept, advanced} 만 매핑하므로 구조적으로 불가)
concept_id != M3_CIRC_C{slot} 인 행       : ★0 / 46
type_name != base + " - " + suffix 인 행  : ★0 / 46
```
★`concept` 은 **유형 층의 default_difficulty 값**으로만 썼고,
문항 층의 `core` 는 이 페이로드에 등장하지 않습니다.

## 5. ★쓰기 승인 시 필요한 상수 — CSV 에 없는 4필드

CSV 는 지시받은 9컬럼만 담았습니다. 실제 카탈로그 엔트리는 **8필드**이고,
그 중 4개는 46건 전부 동일한 상수입니다. **승인 시 이 값으로 채웁니다.**

```
엔트리 필드 8개 (기존 47종 기준)
  problem_type_id     ← CSV
  unit_id             = "M3_CIRCLE_PROPERTIES"     상수
  unit_name           = "원의 성질"                 상수
  type_name           ← CSV
  type_name_source    = "variant_bank"             상수 (기존 47/47 동일)
  concept_ids         = [ <CSV concept_id> ]       ★배열. 원소 1개
  default_difficulty  ← CSV
  error_tags          = [ ]                        상수 (기존 47/47 빈 배열)
```
★`concept_ids` 는 **문자열이 아니라 원소 1개짜리 배열**입니다. 기존 47종이 전부 그렇습니다.
★`error_tags` 는 기존 47종이 전부 **빈 배열**입니다. null 이 아닙니다.
