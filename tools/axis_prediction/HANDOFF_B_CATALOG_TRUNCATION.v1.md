## 12. ★D안 — 문항 주도 복원 (검수 판정 10차 §3, 채택)

```
원칙   90종을 미리 만들지 않는다
       문항이 요구할 때, 그 자리 하나만 만든다
```

### 결손 90종의 이름은 대부분 창작이 아니다 — 우리 §4 결론의 정정
| 구분 | 종수 | 이름 조달 방법 |
|---|---|---|
| 2칸 보유 28슬롯 + 1칸 보유 22슬롯 | **72** | base 이름 보유. 접미사는 3종 고정 → `base + " - " + 접미사`로 **기계 도출** |
| 슬롯 자체 공백 중 1·3·6·46 | **12** | 앞뒤 순서로 base 이름 **추론 가능**(§13 진행 2번 대상) |
| 슬롯 31·36 | **6** | ★진짜 불명. 창작 영역이라 보류 |

닮음 접미사 3종(고정): `개념·조건 판별` / `비례식·정리 적용` / `복합 계산·증명`
예) 슬롯13 `종이접기에서 닮은 삼각형 찾기`(현재 pos2만) → pos1 `… - 개념·조건 판별` · pos0 `… - 복합 계산·증명`

### 절차
```
1  1,200문항(우선 405 의심분)을 base 단위로 재판정  — base 53종 + 추론 4종. 접미사는 이 단계에서 정하지 않음
2  base가 확정되면 그 문항의 접미사를 판정
3  필요한 칸이 비어 있으면 그때 엔트리 1개 생성 (이름은 기계 도출)
4  아무 문항도 요구하지 않은 칸은 만들지 않는다
```
원의 성질 §1-②("관측된 접미사만 생성")를 그대로 적용한 것. **원의 성질 편입은 닮음에서 D안이 성립하면 같은 방법으로 재개**한다.
