## 4. 🔴 새로 발견한 진짜 문제 — 학습지 라벨과 전사 본문이 다른 건

`simpy-06 q62` 에서 **학습지가 인쇄한 유형명**과 **전사된 본문**이 서로 다른 문제를 가리킵니다.

```
학습지(set06 q62)  삼각형의 중점을 연결한 선분 응용(2) 삼등분선   -> 슬롯 30
전사 힌트          직사각형에서 연속된 수직 조건으로 닮음을 반복 적용해 AH 구하기
                  (AB=4, AD=6, E는 BC의 삼등분점)
배정               PT036 = 슬롯 12 (직각삼각형 닮음의 길이·넓이 응용)
검수 판정          슬롯 12 가 맞다 (풀이가 △ABE∽△BCF 반복)
도구 판정          BASE (슬롯 12 -> 30)  ★학습지를 정답으로 삼았기 때문
```

**국소 어긋남이 아닙니다.** q58~q67을 나란히 보면 나머지는 전부 정합합니다.
```
q58·q59  중점연결 응용(1) 중점      힌트도 중점연결      정합
q60·q61  중점연결 응용(2) 삼등분선   힌트도 중점연결      정합
q62      중점연결 응용(2) 삼등분선   힌트는 직사각형 수선  ★불일치
q63·q64  사각형 각 변 중점 사각형    힌트도 동일          정합
q65~q67  사다리꼴 중점연결          힌트도 동일          정합
```

### 해석 — 출판사 분류와 풀이법이 갈립니다
문제에 **삼등분점**이 등장하므로 학습지는 이를 `삼등분선` 블록에 넣었고, 실제 풀이는 **직각삼각형 닮음**입니다.
⇒ **학습지 라벨 = 출판사의 배치 기준 분류**이고, 반드시 풀이법과 일치하지 않습니다.

```
판정 요청  무엇을 정답으로 삼습니까
  (A) 학습지 라벨   canonical taxonomy 가 이 라벨로 만들어졌으므로 일관됨   ★Code탭 권고
                   단, 이런 건이 BASE 103 안에 섞여 있습니다
  (B) 풀이법       진단 정확도에는 이쪽이 맞으나, 문항마다 본문 판독이 필요
```
★ (A)를 권고하되, **BASE 103건 안에 (A)/(B)가 갈리는 건이 얼마나 되는지는 본문 없이 셀 수 없습니다.** 검수가 본문을 보유하고 있으니, BASE 후보 판정 때 이 축을 함께 봐 주십시오.
