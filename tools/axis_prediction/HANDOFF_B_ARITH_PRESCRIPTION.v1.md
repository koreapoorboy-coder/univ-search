### ★★M1 재태깅 근거 — 검수 논리 정정 (검수 판정 2026-08-18)

**최종 제출·인계문은 반드시 아래 정정본을 쓴다. 정정 이전 서술(신설률 근거)은 인용하지 말 것.**

| | 폐기된 근거 | **정정된 근거** |
|---|---|---|
| 주장 | "커버리지가 낮으면 신설이 늘어난다" | "커버리지가 낮으면 **검증이 불가능**해진다" |
| 지표 | 신설률 | **판정불가율** |
| 실측 | 100%→0 · 34%→0 · 19%→**8** (단조적이지 않음, 반증됨) | 100%→0% · 34%→**이론 34.6%** · 0%→**100%** (거의 단조적) |

※ 수연산 값은 **편성 무관 이론값 34.6%**(전 범주 저작 완료 시점, 카탈로그+overlay로만 결정)를 쓴다. 진행 중 값(100종 30% · 144종 24.3% · 166종 26.5%)은 편성의 함수라 단원 간 비교에 쓸 수 없다.

**왜 신설률이 근거가 될 수 없나**: tier-2(단원 관측 어휘 풀 91종)가 자기 overlay 부재를 대신 받는다. 수연산은 커버리지가 M2_GEOM보다 높은데 신설은 더 적고(0 vs 8), 배치6은 overlay 10%에서도 신설 0이었다.

**두 지표가 재는 것이 다르다**
- 신설률 = **태그를 붙일 수 있는가**(저작 가능성) → 단원 관측 어휘 풀의 크기·범용성이 결정
- 판정불가율 = **붙인 태그가 맞는지 확인할 수 있는가**(검증 가능성) → **커버리지가 직접 결정**

⇒ **커버리지가 낮아도 처방은 쓸 수 있으나, 그 처방이 맞는지 확인할 수 없다.** 이것이 M1 재태깅의 진짜 근거다.

**★실물 예시(검수 지시로 보존)**: 배치6 등식의 변형 7범주 17종(`M2_NE_PT195`~`PT211`). tier-2로 태그가 전부 붙었고 검증 13항목도 통과했지만, 개념 내 관측 유형이 0이라 맞는지 확인할 수단이 없다. **M1 전 단원이 정확히 이 상태다.**

**모든 `.ps1` 상단에 ASCII 자기검사 블록**이 들어간다(`param()` 직후). 스크립트가 **자기 파일의 비ASCII 바이트를 세어 1개라도 있으면 실행을 거부**한다. 주석 안의 한글도 차단된다.
신규 도구는 `new_tool.ps1`로 만들면 이 블록이 처음부터 포함된다.

```
powershell -File tools\axis_prediction\new_tool.ps1 -Name my_tool.ps1 -Purpose "what it does"
```

**★알려진 사각지대**: 파일 경로 없이 실행하면(내용을 파이프로 밀어 넣는 방식) `$MyInvocation.MyCommand.Path`가 null이라 검사가 건너뛰어진다. **도구는 반드시 `powershell -File <경로>` 형태로 실행할 것.**

**즉시 적발된 것**: 설치 직후 `edit_json_meta.ps1`에 **기존 비ASCII 3바이트**(주석의 `★`)가 있어 실행이 차단됐다 → ASCII로 교체. 가장 중요한 도구에 이미 위반이 있었고, 그동안 아무도 몰랐다.

### ★★[14] `_meta` 식별자 키 ASCII — 왜 도구로 강제하는가 (검수 지적 2026-08-18 2차)

## 6. ★이 세션에서 새로 등재한 함정 (인계문 §7에 반영됨)

1. **PS 한글 "리터럴 인코딩" 오염** — BOM 없는 `.ps1`에 한글을 직접 쓰면 실행 전에 이미 깨진다. 스크립트는 **오류 없이 정상 종료**하고 깨진 값이 데이터에 기록되며 **JSON 파싱도 통과**한다. 실사고: 닮음 병합 시 `course` 리터럴 1개가 **261건 오염**. → `.ps1`은 ASCII 전용, 한글은 데이터/패치 파일에서만.
2. **U+FFFD 스캔 상시화** — 인코딩 손상은 문법 오류를 안 내므로 파싱 통과로는 못 잡는다.
3. **`_meta` 구조 편집은 텍스트 치환 금지**(2회 파손) → `edit_json_meta.ps1` 경유.
4. **PS 변수명 대소문자 미구분** — `$FFFD`(문자)와 `$fffd`(개수)가 같은 변수. 도구가 스스로 오탐을 냈다. ★**도구를 만들면 정상 통과와 실패 케이스를 둘 다 시험할 것.**
5. **억제 건수 ≠ 카탈로그 종수**(2회) — 스코프는 반드시 `problem_types` 실집계로.
