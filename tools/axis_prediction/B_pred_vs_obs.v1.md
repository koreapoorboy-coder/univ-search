## 해석 — predicted=요구 vs observed=실패 (46% 겹침)
- **합의 축 = C1(식세우기)·E1(검산).** 팩이 예측한 축을 태그가 같은 문항에서 확인.
- **벌어짐이 구조적**:
  - **태그≫팩: D3(계산실수)·C2(개념혼동)** — 학생이 실제로 더 많이 틀리는 곳. 팩은 유형명에서 이걸 예측 안 함.
  - **팩≫태그: A2(암기형)·B3(경우분류)·D2(공식)·A1·C3** — 팩은 "문제가 뭘 요구"를 봄. 태그는 학생 실패라 이 축들을 잘 안 붙임.
  - **E3: 같은 규모(29/28)인데 겹침 0** — 단위/답형식을 팩·태그 둘 다 보지만 서로 다른 문항에서.
- → 첫 인계문의 "팩=문제가 뭘 요구(예측), 태그=학생이 뭘 실패(실측), 이 간극이 채점 로직의 핵심"이 **문항 단위로 실측됨.**

## ★ clean E1 검증 (①과 맞물림)
falsepos(C-01) 걸러낸 뒤 팩 E1 61개 중 **43이 태그 E1과 겹침.** 오탐 경로 제거한 E1은 관측이 확인 → E1(검산) 축이 예측·관측 양쪽에서 실재. (오탐 92문항 E1은 이 표본서 이미 제외됨.)

## ★ E3 겹침 0 규명 (버그 아님 — predicted≠observed의 E3판)
E3 팩29·태그28인데 겹침 0. 눈 확인 결과 **두 집단 서로소**:
- **팩 E3 문항**: 태그가 formula_selection·geometric_modeling·condition_omission(=D2·C1·B1). unit_conversion 없음 → 관측 E3 없음.
- **태그 E3 문항**: unit_conversion_error(→C4,E3) 있으나 팩은 B2,C1 예측(E3 아님).
- → **조인 버그 아님.** 같은 축(답형식·단위)을 **팩=구조적(문제에 단위 있음)·태그=행동적(학생이 단위 틀림)** 으로 **다른 문항에** 부착. D3와 같은 종류의 predicted≠observed 실물.
