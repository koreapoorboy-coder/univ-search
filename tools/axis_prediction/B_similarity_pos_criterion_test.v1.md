## 1. §2 — pos 기준 검증

### 1-1. 시험 설계
```
정답이 알려진 입력 = D1 의 기존 배정분 1,189건 (문항수 1,650 중 배정 보유분)
분류 기준(source_note 기계 판정)
  판별형  판별|고르|찾기|옳은|옳지 않은|아닌 것|구별|짝지어|맞는 것|판단  이 있고 계산어가 없음
  계산형  구하기|구하시오|계산하기  가 있고 판별어가 없음
  (둘 다이거나 둘 다 아니면 제외)
```
★ 판정 26차 §3 대로 **검사 범위·비교 방식·제외 대상을 먼저 정했습니다.**

### 1-2. 순방향 — pos0 에 판별형이 몰리는가 : ★예
```
pos0   판별형 39 / 153  = 25.5%
pos1   판별형 11 / 663  =  1.7%
pos2   판별형 15 / 373  =  4.0%
```
pos0 이 pos1 의 15배입니다.

### 1-3. ★교란 통제 — 칸이 1개뿐이면 선택의 여지가 없었습니다
```
칸이 2개 이상이라 실제로 고를 수 있었던 슬롯만 남기고 재계산
```
```
                       전체            교란 통제 후
판별형 -> pos0    39/65  = 60.0%     39/55 = ★70.9%
계산형 -> pos0   100/1062 =  9.4%    81/755 = 10.7%
계산형 -> pos1   617/1062 = 58.1%   401/755 = ★53.1%
계산형 -> pos2   345/1062 = 32.5%   273/755 =  36.2%
```

### 1-4. ★판정 — 절반만 통과합니다
```
✔ 지지됨   "판별형 -> pos0"     70.9%.  계산형의 10.7% 대비 ★7배. 우연이 아닙니다
✘ 미지지   "계산형 -> pos1"     53.1%.  pos2 36.2% 와 견줘 ★사실상 갈리지 않습니다
```
```
⇒ 검수 판정 34차 §2 의 두 갈래 중
   PT007(pos0) 2건  ← 근거 있음 (0710-02 q005 · 0710-03 q005, 둘 다 판별형)
   PT008(pos1) 2건  ← ★근거 없음 (0710-01 q007 · q008, 둘 다 계산형)
                       계산형은 pos1 53% / pos2 36% 로 갈리지 않습니다
```
★ **"형식(보기 고르기)으로 pos0 을 고른 것이 폐기된 방법과 형태가 같다"**는 우려는
**절반만 맞았습니다.** 판별형 판정은 실측이 뒷받침하고, 계산형을 pos1 으로 민 쪽이 근거가 없습니다.

### 1-5. 285건에 대한 함의
```
B 285건 중 판별형이면      -> 70.9% 로 pos0. 쓸 수 있는 근거입니다
B 285건 중 계산형이면      -> 갈리지 않습니다. 기존 보류가 맞습니다
```
★ 판정 34차 §3 이 "§2 검증이 285건의 향방을 결정한다"고 했는데,
**결정된 것은 285건 중 판별형 부분뿐입니다.** 그 규모는 요청 주시면 세겠습니다.

## 2. §4 — 미매핑 8종 재분류

`align_catalog_to_mathflat.ps1` 을 돌려 mathflat 번호와 정렬 슬롯을 도구로 확인했습니다.
제출13 의 서술이 아니라 **정렬 산출로 확인한 것**입니다.

```
라벨                                    mf     정렬 슬롯   슬롯 칸수   분류
다면체에서 닮음비의 응용                   mf#6      4          1      ①-> A 배정가능
피타고라스 나무 문제                       mf#76    58          1      ①-> A 배정가능
항상 닮은 도형                            mf#2      2          2      ①-> B 보류
평면도형에서 닮음의 성질                   mf#3      2          2      ①-> B 보류
변의 길이에 따른 삼각형의 종류              mf#69    56          2      ①-> B 보류
피타고라스 정리의 활용(3) 직사각형 내부의 점  mf#73    57          3      ①-> B 보류
각기둥에서의 최단 거리                     mf#80    59          2      ①-> B 보류
입체도형에서 닮음의 성질                   mf#5      3          0      ★② 자리확정·미생성
```
```
① 병합 판정이 이미 난 것   ★7종 56건
② 자리가 확정된 것          1종  4건 (슬롯 3)
③ 진짜 미매핑              ★0종
```
★ **검수 §4 의 우려가 맞았습니다.** `평면도형에서 닮음의 성질` = mf#3, `다면체에서 닮음비의 응용` = mf#6
으로 제출13 기록과 일치하고, **나머지 5종도 전부 점유 슬롯으로 정렬돼 있었습니다.**
"카탈로그에 자리가 없다"가 아니라 **"라벨→슬롯 맵이 낡았다"** 입니다.

### 2-1. 맵에 반영하면 규모가 이렇게 바뀝니다
```
                     현재        7종 반영 후
A_single_cell        137        ★158   (+21: 다면체 9 + 피타고라스 나무 12)
B_multi_cell_hold    285         320   (+35)
D_no_slot             39           4   (슬롯 3 요구 4건만 남음)
NEWLABEL(별도 집계)    21           0   ★소멸
```
★ 단 이 정렬은 **mathflat 순서 DP** 산출이고, 빈 슬롯에 대한 적중률이 4/6=67% 였던 방법입니다.
지금 7종은 **점유 슬롯**으로의 병합이라 성격이 다르지만, 그래도 **Code탭이 맵을 고치지 않았습니다.**
반영 여부를 판정해 주십시오.


### 3-2. ★롤백 불가 — 워커 코드 확인
판정 34차 §1 이 "워커가 빈 값 지정을 지원하는지 먼저 확인하라"고 해서 코드를 봤습니다.
```js
// worker_skeleton/math_diagnosis_worker.js  bulkAssignType()
if (!a.id || !a.problem_type_id) { notfound.push({ id: a.id, reason: 'id·problem_type_id 필수' }); continue; }
```
```
⇒ 빈 problem_type_id 는 ★notfound 로 빠지고 UPDATE 되지 않습니다
⇒ "빈 값으로 되돌리기" 형태의 롤백 페이로드는 동작하지 않습니다
```
### 3-3. ★부수 효과 하나 더 — status 도 바뀝니다
```js
UPDATE user_items SET problem_type_id=?1, status=?2, ... // status = 'approved'
```
```
유형을 붙이면 status 가 ★approved 로 함께 바뀝니다
롤백하려면 problem_type_id 뿐 아니라 status 도 되돌려야 하는데,
이 엔드포인트는 status 를 임의값으로 되돌리는 경로가 없습니다
```
### 3-4. 대안 경로와 그 한계
```
/api/user-items/rollback-batch   배치 단위 soft-archive 또는 hard-delete
                                 ★문항 단위가 아니라 배치 전체입니다
                                 137건은 5개 배치에 걸쳐 있고, 그 배치에는
                                 건드리면 안 되는 문항이 함께 있습니다
⇒ 사용할 수 없습니다
```
```
★결론  A 137건 배정은 ★되돌릴 수 없습니다
요청   판정 34차 §1 지시대로 이 사실을 명시하고 진행 여부를 다시 판정받습니다
       ★Code탭 의견: 되돌릴 수 없더라도 손실 위험은 낮다고 봅니다
              현재 값이 비어 있어 잃을 값이 없고, 칸이 1개뿐이라 선택 오류가 없으며,
              최악의 경우가 "base 는 맞고 칸이 틀림"인데 base 는 라벨이 확정합니다
       ★그래도 판정은 검수 몫입니다. 임의로 진행하지 않습니다
```
