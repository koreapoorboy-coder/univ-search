# 문항 매칭 임계값 실험 (정규화·유사도·숫자) (2026-08-10)

> 검수 요청: 99% 임계값 검토. 정규화 후 점수 상승·하한/상한 분포·안전 임계값 제안.
> 결론: **유사도 단일 임계값 불가**(숫자만 다른 동일유형 문항과 겹침). **정규화 + 숫자 시퀀스 정확일치 + 타입필터** 복합 규칙 필요.

## 방법
- 정규화: 위첨자→^n(²→^2), 공백 제거, ×·−류 기호 통일, 문장부호 제거, 소문자화.
- 유사도: 문자 bigram Dice.
- 숫자 시퀀스: 본문의 모든 숫자열 추출·순서비교.

## 해석
1. **정규화 효과 큼**: 표기만 다른 같은 문항 raw 0.66~0.71 → norm **1.000**. 정규화 필수.
2. **★상한 위험**: 숫자만 다른 문항(C) norm 0.76~0.85 = 같은문항 OCR오독(B1) 0.863과 **겹침**. → 유사도 θ 하나로 못 가름(θ=0.86이면 B 놓침, 0.84면 C 오매칭).
3. **숫자 시퀀스가 완벽 판별**: 같은문항 Y, 숫자만다름 N.

## 제안 매칭 규칙
`같은 problem_type_id(타입필터) AND 정규화 숫자시퀀스 정확일치(주판별) AND 정규화 유사도 ≥ 0.80(보조) AND 2위 마진 ≥ 0.05` → 아니면 미매칭(AI 폴백).
- 오매칭 0 수렴(숫자 다르면 무조건 미매칭). 미매칭률은 AI의 **숫자 오독률**에 좌우 → 사용자 실데이터로 실측(match_lab.html).

## 한계·후속
- 위 pair는 구성 모델. 표기·숫자 성분은 정확하나 **실 AI OCR 오독률(비숫자·숫자)**은 라이브 필요 → `match_lab.html`로 사용자 실데이터 대조.
- 재현 perl 스크립트: 아래.

```perl
# 정규화
sub norm { my $s=shift;
  $s=~s/²/^2/g; $s=~s/³/^3/g; $s=~s/¹/^1/g; $s=~s/⁴/^4/g; $s=~s/⁵/^5/g;
  $s=~s/×/*/g; $s=~s/·/*/g; $s=~s/−/-/g; $s=~s/–/-/g;
  $s=~s/[.,·、。]//g; $s=~s/\s+//g; return lc($s); }
# 문자 bigram Dice
sub dice { my($a,$b)=@_; my(%ca,%cb);
  my @A=split//,$a; for my $i (0..$#A-1){$ca{$A[$i].$A[$i+1]}++}
  my @B=split//,$b; for my $i (0..$#B-1){$cb{$B[$i].$B[$i+1]}++}
  my($na,$nb,$in)=(0,0,0); $na+=$_ for values%ca; $nb+=$_ for values%cb;
  for(keys%ca){my $m=$ca{$_};my $n=$cb{$_}//0;$in+=$m<$n?$m:$n} return $na+$nb?2*$in/($na+$nb):0; }
sub digits { my @d=(shift=~/(\d+)/g); return join(",",@d); }
```
