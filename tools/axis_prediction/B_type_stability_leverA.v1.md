## 2. 레버 A = 범주 2단계 (검수 승인)

유형 배정을 (범주 선택 → 그 범주 유형만 재제시)로 2단계화. 선택지 140→평균 10.

### A의 한계 (사전 명시, 검수 지적)
오늘 관측된 이동 중 **범주 내 이동이 존재** → A로 안 잡힘:
- PT050 ↔ PT053 : 둘 다 "삼각형의 내심". lead 태그 동일 → **A 무효**.
- PT116 ↔ PT065 : 도형활용 ↔ 평행사변형 → 범주 간, A로 해결 가능.
- PT128 ↔ PT053 : 삼각형의 성질 ↔ 삼각형의 내심 → 범주 간, 해결 가능.

∴ A는 **범주 간 이동만** 잡음. 범주 내 잔여량이 B·C 판정 근거.

### 구현 요건 (검수)
1. 1단계 범주 선택에도 **"없음"(NO_MATCH) 허용** — 억지 범주 선택 금지(차단2 원칙).
2. `_staged`에 **category_assigned · category_confidence** 기록 — 어느 단계에서 흔들리는지 분리 측정.
3. **VERSION 갱신 필수.** 배포 후 /health 확인.
4. 콜 수 증가(현행 대비). **비용 영향 실측 포함** (현재 50문항 $2.03).
5. **범주 오선택 실패 모드 설계 포함** — 1단계 범주 선택도 AI 호출이라 비결정적(14중 선택, 분산 작으나 0 아님). 범주 오선택 시 2단계가 잘못된 후보군을 받음 → NO_MATCH 폴백 등.
