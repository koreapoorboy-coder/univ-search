# 유형 예측표 (predicted_axes) — 규칙 + 생성 스크립트

45단원 분류표의 각 유형에 대해 「여기서 잘 틀리는 축」을 규칙으로 예측한다.
분류표(어디에 속하는가)와 별개이며, **predicted_ 전용** — 학생 실측(observed_)과
절대 같은 필드에 저장하지 않는다.

### 패치 반영 방식 (파일 전송 실패 시)
검수 채팅→Code 탭 파일 전송이 불안정할 때(zip 3회 중 2회 유실), 규칙 블록을 **채팅 본문에
JSON 텍스트로** 받아 반영한다. 절차: v(n) 을 복사→`domain` 끝에 블록 텍스트 삽입→`version` 만 상향.
**재직렬화 금지**(ConvertTo-Json 은 한글 escape·키순서·공백을 바꿔 기존 팩의 바이트동일성을 깬다) —
텍스트 삽입으로 기존 팩을 바이트 보존하고, 삽입 후 common+각 팩을 v(n)과 대조 검증한다.
정규식 `\\(` 는 JSON 문자열에서 `\(` 가 되므로 두 백슬래시 그대로 둔다.
- **기존 팩 수정이 필요한 경우(v9 CA2_M2D)**: 바이트동일 불변식을 그 팩만 완화한다 —
  `applies_to`·`note` 등 지정된 필드만 문자열 치환(치환 매치 수=1 확인), 나머지 팩은 완전 동일,
  수정 팩도 `rules` 배열은 바이트 동일. 다른 단원(예: M2D)의 실행 결과 불변을 재실행으로 확인.

### PF 코드 충돌 처리 (v4 호출 규약)
`PF` 는 소인수분해(M1S1)·다항식곱셈(M3S1) 두 단원에 붙는다. 팩은 prefix 로 선택되므로
호출 키를 **`PF_M1S1` / `PF_M3S1`** 로 갈라야 팩이 안 섞인다(Python 은 CLI 인자, 포팅은
`unit_code=PF → PF_$학기` 매핑). 규칙 `applies_to` 도 `["PF_M1S1"]`. 나머지 44단원은 prefix 유일.

    이후 `$R.domain.$pk`가 `$null` → 재사용 커버율이 전부 **거짓 0%**. `$p`/`$P` 경로 충돌과 동형.
    (초기엔 해시테이블 `.name`으로 오진했으나 GS·CP의 진짜 원인은 이 변수 충돌.)
    **안전 규칙: `$R`이 살아있는 스크립트에서 `$r`·`$p` 같은 1글자 루프변수 금지. `$row`·`$rule`·`$pk`·`$packName`만 쓸 것.**
    검증된 스니펫:
    ```powershell
    foreach($row in $rows){ $ctx="$($row.묶음) $($row.이름)"; foreach($rule in $R.domain.$pk.rules){ if($ctx -match $rule.pattern){$cov++;break} } }
    ```
