```

  q043 <-> q044   0.752   동심원 반지름비 2:3 vs 3:4
  q025 <-> q027   0.751   두 원 접선 PA=10,BD=14 vs PA=7,BD=10

```

## 5. ★확인 불가 1건 — q040 선택지 ①

전사자가 본문이 아니라 **`explanation` 안에** 이의를 적어 두었습니다.

```
q040 선택지  ① 24/2 cm  ② 25/2 cm  ③ 13cm  ④ 27/2 cm  ⑤ 14cm
explanation 끝  "(참고: 선택지 ①은 PDF에 '24/2 cm'로 인쇄되어 있어
                 약분되지 않은 형태 그대로 옮겼다.)"
```

**Code탭은 이 이의를 확인도 반박도 할 수 없습니다.**

```
pdftotext 로 260711_원의 성질(1).pdf 추출 -> 150문항인데 ★20,428자뿐
  = 문항 본문·선택지가 ★텍스트층에 없다(이미지). 헤더·번호만 텍스트다
Read 도구로 10쪽(q040 이 있는 쪽) 직접 열기 시도 -> ★"pdftoppm is not installed"
  = 판정 이력에 기록된 그대로다. 이 환경에서 PDF 페이지 렌더링은 불가
```
★**이것이 애초에 프로브가 '유형명·정답률'만 뽑는 이유**입니다. 본문은 텍스트층에 없습니다.

**판정 요청 2건**

```
① 사실 확인   '24/2 cm' 가 정말 인쇄된 값인가.
              ★PDF 이미지를 볼 수 있는 쪽(검수·클로드 전사 채팅)만 확인 가능
              맞다면 출판사 오식이고, 전사자가 원문 보존을 택한 것은 옳은 판단이다
② 기재 위치   ★이의를 explanation 에 넣는 것이 맞는가.
              explanation 은 ★학생에게 제시되는 풀이다. 조판 오식에 대한 메모가
              풀이 본문에 섞이면 학습 산출물이 오염된다
              권고 = 이런 메모는 source_note 의 "메모:" 구획으로 옮긴다
              (이미 "메모: PDF 유형명 …, 정답률 …" 을 담는 자리가 있다)
★결함은 아니다. 전사자가 임의로 25/2 로 고치지 않고 원문을 보존한 뒤 밝힌 것은
  올바른 처리다. 위치만 문제 삼는다
```
