### 4-3. ★그런데 set 번호가 하나 어긋난다 — 판정 요청

위 세 확정값을 나란히 놓으면 규칙이 하나로 모이지 않는다.

```
무접미사  -> set01      ┐
(10)      -> set11      ┘  이 둘은 "(N) -> set(N+1)" 규칙에 맞는다 (원의 성질과 동일)
(6)       -> set6       ★그런데 이 규칙대로면 (6) 은 set07 이어야 한다
```

가능한 읽기는 둘이고, **어느 쪽인지 Code탭이 정하지 않는다**(지시 §하지말것 "배치ID 를 정하지 말 것").

```
(가) set6 파일명이 잘못 붙은 것이고 내용은 set07 이다
     방증: 파일명 표기가 set01 / set6 / set11 로 ★영패딩이 들쭉날쭉하다.
           set01 만 두 자리다. 즉 이름이 규칙적으로 붙지 않았다
(나) set 번호가 애초에 체계적이지 않다
```
★**내용 대응(어느 태깅본이 어느 PDF인지)은 1.0000 으로 확정됐다.**
불확실한 것은 그 태깅본에 붙은 **번호의 의미**뿐이다.
검수가 배치ID 표를 만들 때 이 한 건을 정해 주시면 됩니다.
