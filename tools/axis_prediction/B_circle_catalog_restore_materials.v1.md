
## 5. ★D안 착수 전에 알아야 할 것 — 빈 슬롯의 이름은 개념층에 없다

빈 슬롯 11개의 base 이름을 개념층에서 얻을 수 있는지 확인했습니다. **없습니다.**

```
① 빠진 개념번호 11개는 ★개념 자체가 존재하지 않는다 (이름도 없다)
② 존재하는 31개도 ★개념명 != 슬롯 base 이름 이다
   일치 7 / 31 · 불일치 24 / 31
   예  C001 개념="원의 중심과 현의 수직이등분선"
            base="원의 중심과 현의 수직이등분선(1)"
       C005 개념="중심에서 같은 거리에 있는 현의 길이"
            base="현의 길이(1); 중심에서 같은 거리의 두 현"
```

★**따라서 빈 슬롯 33칸의 이름 출처는 §3-2 의 "없는 13종" 학습지 라벨뿐입니다.**
그리고 그 13종이 11슬롯보다 2개 많다는 것이 §3-3 입니다. 두 사실이 한 문제입니다.
